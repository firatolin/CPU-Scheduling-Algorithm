## Project Overview
This project was developed as a group assignment for the Operating Systems course. 
The objective of this project is to understand and implement different CPU scheduling 
algorithms and analyze their behavior in managing process execution.

The implementation is done using C++ and executed in Dev-C++.

## Scheduling Algorithms Implemented

### 1. Shortest Remaining Time First (SRTF)
- Preemptive scheduling algorithm
- Executes the process with the smallest remaining burst time
- Allows process preemption

### 2. Round Robin Scheduling
- Time-sharing scheduling algorithm
- Each process gets a fixed time quantum
- Ensures fairness among processes

### 3. Multilevel Queue Scheduling
- Processes are divided into multiple queues
- System processes use Round Robin scheduling
- User processes use First Come First Serve (FCFS)
